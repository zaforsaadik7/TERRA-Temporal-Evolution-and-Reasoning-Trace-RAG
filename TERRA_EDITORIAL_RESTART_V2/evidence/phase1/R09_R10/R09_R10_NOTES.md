## R09 — External benchmarks

### What each benchmark measures
- **CaseFacts T1 (N=120 claims × 3 pipelines = 360).** A 3-class claim classification (67 Supported / 45 Refuted / 8 Overruled). The label is the judge-parsed label (`parsed_label`). "Outside Precedent Corpus" predictions count as errors. Source: scripts/compute_casefacts_metrics.py → scratch/casefacts_summary_stats.json. All macros reproduce from the raw file (r09_recompute_out.txt).
- **CaseFacts T2 (N=50 × 3).** The refusal rate on post-1980 claims. Refused = parsed_label is OOC, or direct_match, or consensus_correct.
- **CLERC T1 (N=120 × 3).** (a) Retrieval R@k/MRR/nDCG for Flat and TERRA only. (b) ROUGE/BLEU against the gold analysis. (c) eyecite citation P/R, pooled over all items (micro). F1 is computed from the pooled P and R. (d) Judge `hallucination_detected` flags, which the paper relabels as "Misapplication". Source: scripts/compute_clerc_metrics.py → scratch/clerc_metrics_summary.json.
- **CLERC T2 (N=50 × 3).** This is not a CLERC task. It is a stress test the authors built themselves.

## R10 — Retrieval / citation constructs

### Semantics (scripts/compute_retrieval_metrics.py)
- **Node recall.** A gold node counts as found if its CAP ID appears as a substring of `context_full`, OR if the first party name of its title (the text before " v. ", when longer than 4 characters) appears as a substring. This is loose: a first party such as "United States" or "State" can match unrelated text.
- **"Full path recall".** This is simply per-query node recall of 100% (every gold node present somewhere). No edge, order or chain structure is checked. "Path"/"chain recovery"/"trajectory" wording (904-907) overstates the construct, which is really all-gold-nodes coverage.
- The script reads terra_baselines_eval_raw.json (legacy). It hardcodes `62\times` / `3.0\times` and does not emit the CI macro.
- The v2 macros (88.9 / 88.3 / 66; 49/16/1) reproduce exactly from canonical_v2 `context_full` with the same matcher. Legacy reproduces 86.08 / 62; 37/20/5 (r10_recompute_out.json). The text at 897 and the table note still cite `terra_baselines_eval_raw.json` as the source.
