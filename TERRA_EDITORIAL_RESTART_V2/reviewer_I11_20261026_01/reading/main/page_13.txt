N = 350 queries. All runs used T = 0.0, Google Gemma 3
12B Instruction-tuned (databricks-gemma-3-12b) via the
Databricks Model Serving API under strict schema valida-
tion (RoutingDecision), with zero fallback contamination
(0/350); the specification, prompt and Pydantic schema
are in docs/ROUTER_SPECIFICATION.md.
1) Intent Classification Performance and Category D
Misroutes: Overall accuracy is 97.14% (340/350) with
macro-F1 96.60% (macro precision 95.45%, macro recall
98.00%). On the factual class (Gold EASY, Category A)
F1 is 95.24% with perfect recall (100.00%, 100/100);
on complex inquiries (Gold HARD, Categories B–D) it
is 97.96% with 100.00% precision (240/240). The False-
HARD rate on factual queries is 0.00% (0/100), and
the False-EASY rate over complex queries is 4.00%
(10/250), with none on Category B (0/100) or Cate-
gory C (0/75). In isolation the router has a median
latency of 1, 126.4 ms (mean 1, 565.5 ms, p90 2, 043.8 ms,
range 601.9–15, 370.2 ms, the maximum an un-cached cold
start).
All 10 misroutes are Category D queries (13.33%,
10/75): D021, D039, D060, D062, D068, D069, D070,
D072, D073, D074. Each is a single-sentence constitutional
inquiry about one landmark (e.g., D021: “Did the Supreme
Court in Mapp v. Ohio establish that police custodial in-
terrogations must be preceded by four-point constitutional
rights warnings?”) with no explicit multi-hop connector,
so the router classifies it by surface simplicity. In the
canonical run the fast route still recorded retrieval and
NLI grading on all 110 queries it handled, so generations
were conditioned on retrieved context, and all ten were
handled safely under dual judging (100.0%, 10/10): 8 were
refused deterministically because the grader did not pass
the context (D021, D039, D060, D062, D069, D072, D073,
D074), and 2 (D068, Lottery Case; D070, oleomargarine
tax) were unflagged textual refusals citing insuﬀicient
context, scored 1.000, with zero fatal violations. This is
consistent with downstream checks limiting the cost of a
misroute, but with ten queries and judge-based scoring it is
a small-sample observation, not evidence that downstream
mechanisms reliably prevent hallucination.
