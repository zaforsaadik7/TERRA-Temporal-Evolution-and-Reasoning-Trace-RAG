## Output schema

`dispositions.json` contains metadata, identities, counts and38 item records. `per_id/AUTH1-ITEM-NNN.json` contains one identical record for each assigned ID. Fields include assessment_id, as_of_cutoff_year, disposition, attribution_finding, fidelity_finding, pinpoint_finding, scope_and_cutoff_finding, evidence, proposed_action_not_applied, unresolved_questions, prior_repair_status and explicit false flags for ratings_reviewed, expert_legal_validation and applicability_proven_by_text_match. Original ledger source/excerpt is retained in each record so versions remain distinguishable.
