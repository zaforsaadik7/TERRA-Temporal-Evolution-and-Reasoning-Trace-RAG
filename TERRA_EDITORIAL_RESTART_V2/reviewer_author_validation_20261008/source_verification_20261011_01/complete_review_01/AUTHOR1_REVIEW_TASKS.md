# Author 1: assessor decision checklist

Prepared 11 October 2026 from the completed source audit. This document requests author decisions; it supplies no replacement ratings. Review only the listed entries. Original workbook row = item number + 1. Do not edit the submitted workbook. Repeated items share an issue, but each candidate answer must receive its own confirmation.

For every ID report: retained / revised / unresolved; original and proposed ratings in affected columns G–L; whether rationale O changes; source and printed page; a short explanation. If nothing changes, explicitly confirm ratings and rationale retained after source review. If uncertain, say unresolved rather than guessing. Quotation or pinpoint defects alone do not establish an incorrect candidate answer or temporal leakage.
