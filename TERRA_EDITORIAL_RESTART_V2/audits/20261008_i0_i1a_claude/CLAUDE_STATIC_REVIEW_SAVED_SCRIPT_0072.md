## Additional findings (not in Codex-0014)
1. **Cache-path mismatch can pass preflight and still trigger a download.** The script checks the six files at a hard-coded `C:\Users\zafor\...` directory, but Chroma's ONNX function looks in its own `DOWNLOAD_PATH` (derived from the home directory of the running user). Derive the path from the installed embedding implementation (or assert the two paths are equal) before querying; otherwise the check certifies a different folder than the one Chroma will read, and the only protection left is the Python-level guard.
2. **Unverified hard-coded claim in the output.** `search_semantics` asserts "unit-normalized embeddings". Nothing in the script checks it. Either compute query-embedding norms with the same embedding function (a separate inference step to specify in the approval) or remove the claim.
3. **Hash the copy after the run.** The copy is hashed only before the queries. Opening a `PersistentClient` can write to a store (WAL, migration); add the post-run copy manifest to the report and compare the active configuration before and after.
4. **Original-stats comparison.** `std_population_ddof0` and `std_sample_ddof1` are both reported, good. The legacy sample is 10 A + 10 B from `terra_175_benchmark.json` (the filter `[:20]` of A+B), and I checked that none of these 40 query texts appear in the 350 benchmark (0/20 and 0/20 overlap), so the sample20 numbers are on genuinely different queries and cannot be pooled with the 350-query result.
5. **A cheap and decisive extension to consider (needs a separate scope decision).** `dataset_10k_cap/vector_db_10k` and `terra_vector_db_10k` exist locally. The 0.365/0.509 figures were tied to a 10k-era index and to the first 20 A+B queries of benchmark175. Running the same legacy sample20 on the 10k store, under the same safeguards, would test directly whether 0.365 ± 0.082 and 0.509 reproduce for that sample. This is a stronger test of line 210's provenance than running it only on the 20k store, but it is outside the approved design (Codex-0012 required a separate approval for a 10k scope) and would also need its own manifest and configuration checks. I raise it as an option, not a request.
