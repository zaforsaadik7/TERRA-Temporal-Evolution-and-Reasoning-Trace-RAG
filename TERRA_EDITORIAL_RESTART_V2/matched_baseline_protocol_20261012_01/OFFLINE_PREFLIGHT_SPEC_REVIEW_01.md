1. **Authorship and sequence.** The specification was authored by Antigravity, not jointly by Antigravity & Codex. Correct by a preserved revision/addendum. Separate specification approval, code-only driver implementation plus synthetic audit, and explicit real-data preflight authorization. Do not combine implementing and running in one next step. The proposed driver does not yet exist; --dry-run/--read-only are proposed flags, not proven controls.

2. **Protect the actual store.** Chroma get() is not proof the client is read-only. Never open the original store through Chroma. Specify an exact store path/collection and verified byte-preserved snapshot, copy its complete file inventory into a fresh disposable directory, run against that copy only, with before/after originals/snapshot manifests. Record copied-store migrations and versions. Guard cached embedding resolution against downloads, bind its exact cached model, and use externally enforced offline conditions for inference. Missing assets produce BLOCKED, not fallback downloads. No existing generators/rebuilders.

3. **Exact corpus parity.** IDs and text lengths cannot prove text equality. Extract actual stored dense documents from the copied store and use those same bytes for BM25, or require per-ID exact content/hash equality for every document. Include duplicates, missing IDs and metadata mapping. Graph nodes may be keyed by ID rather than contain case_id; validate the authentic schema, not an invented one. Inspect known manifests first; propose the specific corrected r30corr_v1 graph rather than guessed eeg_graph.json paths. Parsing a compressed graph is a separately scoped read, even without changing it. Date/holding missingness must be reported against a frozen policy; do not silently drop nodes or demand completeness inconsistent with the preserved corpus.

4. **Annotation parity.** Reaffirm the shared query-independent relation catalog and deterministic support excerpts for both arms. Any neighboring text is charged to the evidence budget. Equal sparse/dense text alone does not certify equal final evidence payloads. Distinguish indexed retrieval text (ingestion uses opinion text[:1000]) from the graph/serializer payload (currently snippet[:600]). Check each representation independently.

5. **Offline envelope, not unknown live routes.** State the full 350-query cohort and evaluate both EASY and HARD packaging envelopes per query, without calling the router or using historical answers/gold IDs for selection. Fifteen pilot questions cannot replace the all-query feasibility check. Include generator, verifier and both judge prompt templates, references if permitted by the rubric, and maximum 4096-token answer reservations. Before live outputs exist, judge counts are upper bounds, not measured actual prompts. Explicitly disclose controlled graph traversal versus historical implementation.

6. **Endpoint/pricing remain unverified.** 128000 is a placeholder, not an authenticated limit for any listed provider. Choose requested generator/router/verifier/judge endpoints and pin official dated context/completion/rate/pricing evidence. Network documentation lookup and artifact acquisition are separately bounded from offline execution. Do not invent hashes for missing files: pin an official revision/source, then verify supplied/acquired assets under approved scope. Cost accounting must cover every model, billable failed attempt/retry, conservative pre-dispatch reservation, missing usage responses and a user-approved global ceiling—not just generator token rates. Synthetic ledger PASS does not prove these integrations exist.

7. **Operational manifest.** Reconcile preflight_scratch versus preflight_results. Use a unique no-overwrite run directory, explicit absolute input/output paths and exact interpreter/command/config hashes. Set directory-level integrity checks, failure reporting in finalization, exit codes, resource limits and no retry. Distinguish FAIL from BLOCKED dependencies; no overall PASS if token packing or corpus parity was not tested. The 35000-character structural ceiling applies to Arm T traversal representation, not arbitrary combined prompts or Arm H evidence; the common token ceiling applies to both. Require fully synthetic lifecycle tests before any real-data run.
