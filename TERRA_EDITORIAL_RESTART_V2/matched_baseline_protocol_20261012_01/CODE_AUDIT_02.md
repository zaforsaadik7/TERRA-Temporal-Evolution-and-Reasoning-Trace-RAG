## Required corrections

1. **Traversal depth broken and parity claim false.** Normal neighbors are marked visited when enqueued; dequeue immediately skips visited nodes, so they never expand. Separate discovered/enqueued versus processed sets. Tests must assert exact paths and depth behavior, including cycles, incoming edges and multiple seeds. High-degree caps are rescaled to 75%/25% of node limit, not recovered fixed 75/25; missing node IDs become placeholder cases. Structural character accounting includes truncated snippet/holding portions but output can emit full holdings and relation text, so 35k is not an output bound. Recovered root source separates rendered neighbors from visited/expanded nodes; requiring exact equality of all outputs is different from simply repeating constants. Implement a documented controlled adapter and synthetic parity fixtures, or propose an explicit new variant before calling it TERRA parity. No real graph queries permitted.
2. **Annotation parity violated.** HybridRetriever sets relation_context=None for every case, while TerraRetriever adds OVERRULES labels relative to seeds. This recreates the reviewer's privileged-annotation confound. Build common query-independent annotations from the same fixture/catalog for both arms, under one serializer and budget. Tests: same selected case has identical annotations in H/T; relationship exists only among allowed evidence units; all added evidence counts against budget. Do not 'fix' by removing all labels from both without a protocol decision.
3. **Live dispatch still not guarded.** Constructor rejects AUTHORIZED_LIVE but accepts arbitrary provider functions in SYNTHETIC_MOCK. SecurityViolationError is never raised by dispatch. Marker/import names alone are inadequate; separate synthetic fixture-only adapters from production adapter capability, validate execution_mode values and test forbidden callback sentinel is never called. Production capability remains entirely unavailable during this code-only stage; mocked tokenizer must never legitimize real callbacks.
4. **Budget/ledger after call.** Router/verifier/generator/judge callbacks execute before record_call enforces ceiling. This permits one extra request after ceiling; a two-judge callback can perform both before either reservation. Failed requests disappear from ledger; errors don't restore durable attempt accounting. Reserve and persist each attempt before dispatch, settle status/usage after, with explicit two-judge handling. Current ledger_file is never written; attempts always default to 1, judge prompt/completion tokens not measured and elapsed time split in half without individual evidence. Monetary ceiling and retry/run budgets remain absent; label placeholders rather than completed safety controls.
5. **Persistence neither exclusive nor atomic nor safe resume.** exists()+write_text lock is race-prone, not create-new. atomic_append_result writes an unused temp file, then directly appends JSONL: a crash can truncate a record. get_completed_query_ids silently ignores corruption; run_pair never checks those IDs before issuing calls. No durable call ledger/manifest/provider hashes, uncertain-call crash reconciliation or duplicate-result prevention. query_id inserted into temp path permits separators/traversal unless validated. lock release deletes any present lock without ownership verification. Implement synthetic tempfile lifecycle with create-new locks, safe IDs, validated manifests, durable per-attempt states, no overwrite/corruption suppression, duplicate execution stop, and explicit manual treatment of ambiguous paid-call completion. No live retries authorized.
6. **Transport-only claim untrue.** Exception catches all except ConfigurationError/SecurityViolationError; ValueError, TypeError, TokenBudgetExceededError and programming errors become API_ERROR. Router callback exceptions still escape without record. Catch only explicit transport exceptions, preserve stage/error evidence; configuration/parity/budget/programming failures stop. Validate scores before persistence (both judge components finite in [0,1], correct count), not only composite during later analysis.
7. **Refutation/answer/refusal classification invalid.** 'overruled by', 'no longer good law' and 'precedent is superseded' are often substantive answers/refutations, not refusal. The new code misclassifies exactly the successful historical-law response the experiment evaluates. Empty output is provider/parse/missing output, not automatically epistemic refusal. Implement prospectively agreed outcome rubric, distinguish premise refutation/substantive answer/explicit abstention/mixed/unknown/technical failure, preserve text and uncertainty. Judge callback is not a complete frozen rubric implementation; prove tests on negation, quoted refusal, substantive overruling explanation, ambiguous and empty outputs without hidden gold runtime inputs.
8. **Retrieval still outside router lifecycle.** run_pair receives evidence already selected, and router is only a recorded label; no EASY/HARD retrieval selection or validated seed adapter. It cannot certify end-to-end query-only behavior. Provide fixture-backed adapters and route-to-retrieval orchestration; do not use benchmark IDs or category to select evidence. Frozen seeded arm-order schedule needs manifest proof; current deterministic ID parity is not yet the accepted randomization plan.
9. **Remaining statistical/status integrity.** No expected cohort/attempted-ID manifest, so omitted questions shrink the primary denominator unnoticed. Analyzer can treat API_ERROR with present scores as valid; validate mutually consistent statuses and score components. When no pair valid, bounds incorrectly returned None despite partially known scores allowing full-cohort bounds. Keep unavailable inference but retain computable bounds. Validate direct statistical-method inputs (finite bounded diffs), positive integer resample counts and expected IDs/categories. No demonstrated oracle for randomization/CI methods remains in the revised 15 tests; retain/add distribution and exact small-n fixtures. Don't claim a useful bootstrap coverage theorem from a single passing fixture.
