## 2. Revised Template & Renderer Architecture

To achieve authentic token measurement without fabricating template outputs, we propose two explicit renderer paths for user/Codex determination:

### 2.1 Option A (Recommended): Minimal `jinja2` Dependency for Official Template Execution
- **Observation:** `tokenizers` is already installed in the local environment, but `jinja2` is missing.
- **Proposal:** Request user authorization for a single, lightweight Python package installation: `jinja2`.
- **Implementation (`JinjaChatTemplateRenderer`):**
  - Reads the official, revision-pinned `assets/tokenizers/judge2/chat_template.jinja` directly.
  - Implements an audited offline Jinja environment binding the standard Hugging Face runtime helpers:
    - `strftime_now(fmt)`: returns a pre-configured or frozen timestamp (e.g., `2026-10-14`).
    - `raise_exception(msg)`: raises `TemplateRenderingError` on invalid channel tags.
    - `tojson`: standard JSON serializer.
  - Renders 100% authentic Harmony strings matching upstream official Hugging Face behavior.
  - Renders 100% authentic Qwen ChatML using the official Jinja string stored in `assets/tokenizers/judge1/tokenizer_config.json`.
- **Integrity:** Zero homemade delimiter logic. 100% byte fidelity to the official templates.

### 2.2 Option B: Restricted Zero-Install Subset Verified Against Golden Fixtures
- **If the user rejects installing `jinja2`:**
  - The general GPT-OSS template remains **BLOCKED**.
  - We define an **explicitly restricted, narrow dialog subset** supporting only single-turn evaluation prompts (system prompt + user prompt) with zero tools, string-only contents, and fixed metadata branches.
  - Every byte sequence produced by this restricted subset must match an independently established golden string and exact token IDs generated by official Hugging Face / Jinja reference outputs.
  - Any request outside this restricted subset (e.g., tools, developer role, multi-turn assistant with thinking traces) raises `UnsupportedTemplateFeatureError` rather than silently approximating.

| **Judge 1** (`Qwen/Qwen3-Next-80B-A3B-Instruct`) | `tokenizer.json`<br>`tokenizer_config.json`<br>`vocab.json`<br>`merges.txt` |

### Integrity Rules:
1. **Zero Path Traversal:** Enforces strict containment within `assets/tokenizers/<role>/`.
2. **Fail-Closed on Mismatch:** If any file is missing, modified, or has an unexpected SHA-256 hash, initialization immediately raises `ConfigurationError`.
3. **No Silent Fallback:** The adapter will **never** silently fall back to `MockBpeTokenizer` or alternative directories.
