### 2. Provenance of the 200/75 Calibration Grid in Table XII Panel B
- **Generating script:** `scripts/compute_budget_and_gate_metrics.py` (authored during Issue #10 resolution, ~2026-09-05/06; backup preserved at `scratch/orig_scripts/compute_budget_and_gate_metrics.py`, SHA256: `69b3707042c6ee31058744f50c8e5f78c1bd93f0c4db60e643bcdb81cb017cd7`). - **Benchmark identity & hash:** `terra_350_benchmark.json` (SHA256: `8144fa81f1e8fe376174a72d7f9570138dcbb54cb2410a80e4ad3d7e52a488e6`).
- **Population definition:**
  - In-domain ($N=200$): Queries with `category in ["A_Factual", "B_Evolutionary"]` (100 Cat A + 100 Cat B).
  - Out-of-domain ($N=75$): Queries with `category == "C_OutOfContext"`.
  - Adversarial ($N=75$): `category == "D_Adversarial"` was excluded from this ROC/calibration evaluation.
- **Vector index identity & path:** `./dataset_20k_cap/vector_db_20k`, collection `thinking_traces` ($20{,}000$ documents).
- **Embedding model:** `sentence-transformers/all-MiniLM-L6-v2` (384 dimensions), instantiated via ChromaDB's default embedding function (`chromadb.utils.embedding_functions.DefaultEmbeddingFunction`).
- **Collection distance metric (Crucial Finding):**
  - Inspected `dataset_20k_cap/vector_db_20k/chroma.sqlite3`, table `collections`, column `schema_str`.

  - In ChromaDB / HNSWlib, the `"l2"` space computes and returns **squared Euclidean distance**:
    $$d_{\text{Chroma}} = \|u - v\|_2^2 = \sum_{i=1}^{384} (u_i - v_i)^2$$
  - `compute_budget_and_gate_metrics.py` evaluated `d >= tau` directly on Chroma's raw returned distance, which represents **squared L2 distance ($d^2$)**, not unsquared Euclidean distance ($d$).
- **Query normalization / filtering:** None. The raw query string `q["query"]` was passed directly to `coll.query(query_texts=all_texts, n_results=1)`.
