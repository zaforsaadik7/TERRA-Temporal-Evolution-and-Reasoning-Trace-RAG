### 3.2 Comparison Granularity & Recursion Bounds
- **Field Coverage**: Compares 17 scalar/tuple/byte fields: `co_argcount`, `co_posonlyargcount`, `co_kwonlyargcount`, `co_nlocals`, `co_stacksize`, `co_flags`, `co_code`, `co_names`, `co_varnames`, `co_name`, `co_qualname`, `co_firstlineno`, `co_linetable`, `co_exceptiontable`, `co_freevars`, `co_cellvars`, `co_lnotab`.
- **Path Portability**: `co_filename` is compared using `PureWindowsPath` equality rather than raw string comparison.
- **Recursive Constant & Nested Code Checking**: `compare_code` traverses `co_consts` recursively (up to recursion depth 64, maximum 2,000 code objects). Nested code objects are subjected to the full 17-field comparison.
- **Buffer Safety**: Marshal payloads are bounded to 128 KiB for caches, 1 MiB for sources; stream reads assert `stream.read(1) == b''` to reject trailing garbage bytes.
- **PEP 552/3147 Header Validation**: Validates `importlib.util.MAGIC_NUMBER`, `flags == 0` (timestamp-based), header `mtime` matches filesystem `mtime`, and header `size` matches source length.
